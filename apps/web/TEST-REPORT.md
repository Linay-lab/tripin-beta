## 驗證中修正

銜接原 HTML 時，原導航會額外推入歷史紀錄，造成返回仍停留 HTML；現在只於銜接首次導覽以 replaceState 取代該次 pushState。旅行篩選維持於 React 共用狀態；路徑變更關閉編輯視窗，防止返回首頁仍覆蓋旅行表單。

手機封面初次測試未先捲動到預覽框，觸控座標落在畫面外；修正測試先捲動後，拖曳與雙指縮放均通過。分段續跑測試的初始化也已修正，不影響產品資料邏輯。

## 差異與未驗證

Next 首頁直接進入本機模式，首次水合時顯示讀取狀態；未移植原離線模擬登入。Next 採 URL 路由；尚未移植功能採整頁 HTML 銜接，而非 React 內頁。收藏編輯、購買狀態等操作仍屬原 HTML 實作。原有備份還原、GPS 模擬、回饋保留但本階段未重跑無關完整測試，未宣稱已移植或重新驗收。

實體手機、Safari/WebKit、真實定位、真實帳號與 Supabase 均未驗證。既有 HTML 僅因原內容保留回饋端點；自動化測試攔截所有外部請求，不會寄信。Next 不提供正式登入或雲端安全保證。

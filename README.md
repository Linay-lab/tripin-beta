# 旅點 TRIPIN · Beta 測試網站

此儲存庫為獨立 Beta 預覽，來源為 [測試開發分支](https://github.com/Linay-lab/travel-studio-preview/tree/feature/tripin-global-smart-shopping)。

## 啟用網站
GitHub Settings → Pages → Deploy from a branch → main / (root) → Save。預期網址：https://linay-lab.github.io/tripin-beta/

## 注意
- 目前資料僅儲存在瀏覽器本機，沒有多人同步後端。
- GPS 需 HTTPS、定位權限且保持網頁開啟，不支援背景定位。
- 找店使用者主動搜尋 Google Maps，分店經緯度仍須自行確認。
- 回饋功能可能送至真實 Google Apps Script，請勿傳送測試或敏感資料。
- 原有正式網站未修改。

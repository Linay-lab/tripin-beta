## 仍需處理，未擅自擴充

- 同步 localStorage 合約不是可直接套用 Supabase 的非同步交易；觀察到過期後才阻擋，並不提供同時寫入的原子鎖。
- 保留歷史資料容忍範圍：未完整驗證每個跨陣列外鍵，不能宣稱所有舊備份關聯都有效；雲端前需關聯預檢與人工確認。
- 欄位對應表中仍有 schema 待定欄位；pending 資料不可丟棄。UUID 映射目前是明確輸入的純工具，沒有實作配置、持久化或遷移復原。
- 收藏與旅行購物是不同角色；非商品／無旅行商品不會自動建立 shopping_items。商品收藏與購物的雙向關聯仍需決定。
